Project Bioenergetics

A survey-weighted analysis of NHANES thyroid panels testing Ray Peat's bioenergetic hypotheses. Three of four pre-registered predictions failed, and the one significant result ran backwards. Aug 2026. Write-up Code

Power Outages and Population Density

Do higher-density states recover from power outages faster? A permutation-tested EDA and a Random Forest outage-duration model on 16 years of U.S. outage data show that it may not be significant. Jun 2026. Write-up Code
